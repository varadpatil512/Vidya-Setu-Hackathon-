# Vidya-Setu — Learn. Do. Prove.

A Coursera-style learning platform with a **Learn → Do → Prove** model. Students must clear an assignment, pass code verification, and survive an AI interview before earning a **verified skill badge**. Flagged submissions go through a **teacher human-verification** layer.

## Tech Stack

- **Backend:** Node.js + Express + Mongoose (MongoDB)
- **Frontend:** React (Vite) + Tailwind CSS + CodeMirror + TipTap
- **Auth:** JWT with role-based access (STUDENT / TEACHER / ADMIN)
- **AI:** OpenAI GPT API with **deterministic mock fallback** (demo works without an API key)
